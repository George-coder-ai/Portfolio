# Portfolio - Katru Sudheer George

A modern, responsive, and beautifully designed personal portfolio website built to showcase my projects, skills, and background. The site features a clean glassmorphism aesthetic with engaging micro-animations and a sleek waveform illustration to reflect my focus on both software and hardware.

## 🛠️ Stack & Technologies
- **Frontend Core**: HTML, CSS, Vanilla JavaScript
- **Design Elements**: SVG path animations, smooth scroll, responsive glassmorphic navigation.
- **Additional Focus Areas**: React.js, Node.js, MongoDB, REST APIs, AWS Hosting, Flutter, and IoT Integration.

## 🚀 Projects
- **Smart Baby Incubator**: Designed and implemented a baby incubator with intelligent monitoring — bridging IoT sensing with real-time safety alerts.
- **IoT-Powered App**: Currently developing an IoT-enabled mobile application in Flutter, connecting devices to a mobile interface in real time.

## 🌟 Features
- **Responsive Layout**: Fluid typography and spacing using `clamp()` functions to ensure the design scales elegantly on all devices.
- **SVG Waveform Animation**: A custom interactive circuit/waveform illustration in the hero section that traces on page load.
- **Fast and Lightweight**: Built without hefty frameworks to ensure maximum performance and minimal load times.
- **Accessible**: Includes `prefers-reduced-motion` media queries for accessible browsing.

## 📁 Installation & Usage
This is a static web page and requires no complicated setup. To view the site locally:
1. Clone the repository:
   ```bash
   git clone https://github.com/George-coder-ai/Portfolio.git
   ```
2. Navigate to the project directory.
3. Simply open `index.html` in any modern web browser.
   - *Tip: You can also serve it via a local development server like VS Code's "Live Server" extension.*
